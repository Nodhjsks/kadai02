# ①課題名
手押し相撲オセロ

## ②課題内容（どんな作品か）
- オセロと手押し相撲を掛け合わせたゲームです。
- 必ずしも置きたい場所に自分のコマを置けるとは限らず、最後まで勝敗が分からないことが醍醐味です。

## ③工夫した点・こだわった点
- 従来のオセロアプリの機能にもあるように、置ける場所には印が表示されるようにし、自動的にコマがひっくり返るようにしました。
- ユニークな点としては、置いたマスの縦横にある相手のコマがすべて自分のコマになる、一発逆転マスを設定したことです。
  あるマスを選択して、手押し相撲の「せーの」ボタンを押してはじめてそのマスが一発逆転マスだと表示されるので、一発逆転マスだけ狙われるということがないようにしました。
-どちらのプレイヤーが選ぶ番であるかを分かりやすく表示させ、獲得マス数、全体のマス、手押し相撲の絵、「せーの」ボタンが一面に収まるように設計しました。
-「最初から」ボタンは誤操作を防ぐために、あえて少し下の方に置きました。

## ④難しかった点・次回トライしたいこと（又は機能）
- AIにコーディングを助けてもらう際に、自分のイメージしているものとは違うものになってしまったことがあったので、最初にしっかりとした仕様書を作ってから作ることを心掛け、
  本来のターゲットやコンセプトから逸脱しないようにしていきたいです。（最初に仕様書を作成することで、手直しする時間も省くことができると思いました。）
- 手押し相撲の勝率は50％にしましたが、それだと運の要素が強くなってしまうと思ったので、選択する側の勝率を少し上げた方が良いのではないかと考えました。
- アニメーションを増やしたり、効果音をつけたりしてみたいです。
